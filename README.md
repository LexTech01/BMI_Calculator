# BMI Calculator 🧮

This is a Python Tkinter project that calculates the Body Mass Index (BMI) 
and gives the health category (Underweight, Normal, Overweight, Obese).

## Features
- GUI built with Tkinter
- Supports image backgrounds
- Displays BMI results and advice

## How to Run
1. Install Python 3
2. Run `python bmi_calcultor.py`
